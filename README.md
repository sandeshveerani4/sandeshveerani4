## Open Source

### **[google/adk-python#5408](https://github.com/google/adk-python/pull/5408)**
Merged fix for a deadlock in Google's Agent Development Kit affecting Gemini 3.1 Flash Live tool calls. Updated `GeminiLlmConnection.receive()` to stream tool call parts immediately instead of waiting for `turn_complete`, while preserving compatibility with older models.

### **[ta-agent-sdk](https://github.com/sandeshveerani4/ta-agent-sdk)**
Production SDK for building voice and text AI agents. Shared workflows across multiple client deployments, multimodal streaming, tool execution, and provider integrations.

### **[mapfirst-sdk](https://github.com/mapfirst-ai/mapfirst-sdk)**
AI-powered travel discovery SDK that turns existing maps into searchable, monetizable experiences with natural-language search, smart filters, and rich property data. Works with MapLibre, Mapbox, and Google Maps.
**Docs:** https://docs.mapfirst.ai

### **[Chatzoo-Plugin](https://github.com/sandeshveerani4/Chatzoo-Plugin)**
OpenClaw channel plugin powering the **[Chatzoo](https://www.chatzoo.ai)** iOS app. Implements webhook-based bidirectional messaging, HMAC-SHA256 request verification, streaming responses, and FCM fallback notifications.
